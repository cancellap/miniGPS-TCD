# miniGPS-TCD

Aplicacao simples para visualizar um grafo e calcular caminhos, usada como base para o projeto TCD.

## Estrutura

- dados.py: dados base do grafo e posicoes fixas para o desenho.
- logica.py: regras e algoritmos (ex: calculo de caminho).
- interface.py: interface grafica.
- mvp.py: ponto de entrada da aplicacao.

## Requisitos

- Python 3.12+

## Como executar

1) Crie/ative um ambiente Python.
2) Execute:

```bash
python mvp.py
```

## Observacoes

Se precisar ajustar o grafo ou as posicoes dos nos, edite dados.py.
